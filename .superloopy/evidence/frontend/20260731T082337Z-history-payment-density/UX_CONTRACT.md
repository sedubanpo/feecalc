# 이력확인·납부/차액 UX 계약

## 사용자와 작업

- 사용자: 반포관 데스크 실무자.
- 작업: 학부모가 수업 일자·유형·시간과 금액을 빠르게 대조할 수 있는 안내 이미지를 생성한다.
- 성공 조건: 캘린더를 유지하면서 긴 상세 목록을 압축하고, 합계와 과금 규칙을 바꾸지 않는다.

## 공간 계약

| 영역 | 노출 | 불변 조건 |
| --- | --- | --- |
| 이력 캘린더 | 항상 표시 | 날짜마다 과목, 유형, 시간을 확인할 수 있다. |
| 이력 상세 | 항상 표시 | 과목→강사→유형 순서로 읽히며 같은 강사는 한 행이다. |
| 납부 상세 | 항상 표시 | 같은 과목·강사의 수업을 한 행으로 묶고 산출 기준을 잃지 않는다. |
| 합계 | 항상 표시 | 기존 계산 결과와 일치하고 tabular 숫자를 유지한다. |

## 오류 복구

- 저장본 로딩 전에 기본 합계 DOM을 복원한다.
- 납부 탭에 진입하거나 저장본을 적용한 뒤 납부 안내서를 현재 편집 행에서 다시 렌더링한다.
- 로딩 실패 시 원본 입력과 저장 목록을 지우지 않고 구체적인 오류 상태를 표시한다.

## 접근성

- 표 헤더는 `scope="col"`, 대과목은 `scope="rowgroup"`을 사용한다.
- 캘린더 이벤트의 시각 순서와 DOM 읽기 순서는 과목·유형→시간으로 동일하다.
- 금액과 횟수는 tabular 숫자를 사용한다.

## 추적성

| 계약 | 구현 | 검증 |
| --- | --- | --- |
| null `innerText` 오류 제거 | `switchTab`, `restoreDefaultPriceSummaryArea` | 실제 오류 저장본 재로드 |
| 이력 캘린더 밀도 개선 | `renderCalendarEventPill`, `renderHistoryReceipt` | 1280px 실제 브라우저 캡처 |
| 이력 강사별 압축 | `renderHistoryReceipt` | 19개 그룹→강사 행 감소 확인 |
| 납부 동일 강사 병렬화 | `renderPaymentReceipt` | 동일 강사 행 수와 합계 확인 |
| 대과목 보조 집계 제거 | `renderPaymentReceipt` | 대과목 셀 텍스트 검사 |
