# 실제 브라우저 시각 QA

## 환경

- 대상: 로컬 `index.html`, 인앱 Chromium, macOS, 한국어 UI
- 기준 폭: 1280px PC 업무 화면
- 입력 장치: 마우스·키보드
- 증적 데이터: 실사용자 정보를 포함하지 않는 익명 fixture
- 검토 방식: 안내 이미지 생성과 동일한 `html2canvas` 경로로 렌더한 뒤 원본 크기로 육안 검토

## 결과

| 화면 | 증적 | 판정 |
| --- | --- | --- |
| 이력확인 | `history-1280.jpg` | 통과 — 캘린더 유지, 날짜별 과목·유형·시간 2줄 표시, 같은 강사의 유형을 한 행 안 2열로 배치, 상태 텍스트의 세로 깨짐 없음 |
| 납부/차액 | `payment-1280.jpg` | 통과 — 같은 강사 한 행, 유형·산출 기준 병렬 표시, 대과목 아래 혼동성 집계 문구 없음, 합계 영역 유지 |

## 확인한 시각 기준

- 카드 중첩과 좌측 장식 띠를 추가하지 않았다.
- 표의 구분선, 행 병합, 열 정렬로 정보 계층을 만들었다.
- 금액·횟수·시간은 고정폭 숫자 정렬을 유지한다.
- 안내 이미지 내부에서 표가 좌우로 넘치지 않는다.
- 상태는 별도 큰 뱃지 대신 해당 유형 텍스트 색으로만 구분한다.
