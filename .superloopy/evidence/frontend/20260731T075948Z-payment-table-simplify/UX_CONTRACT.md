# 납부/차액 줄표 UX 계약

## 사용자와 작업

- 사용자: 반포관 데스크 실무자
- 작업: 이전 달 Access 수강료·납부·조정 내역을 학부모가 읽기 쉬운 한 장의 안내서로 정리
- 성공: 대과목, 강사, 시간/횟수 기준, 금액을 행 단위로 빠르게 비교하고 최종 차액이 정확함

## 변경 계약

1. 안내서 수업 내역은 하나의 줄표로 표시한다.
2. 열 순서는 `과목`, `강사·수업`, `산출 기준`, `금액`이다.
3. 같은 대과목은 첫 번째 열의 하나의 병합 셀로 묶는다.
4. 왼쪽 색 띠와 과목별 카드 배경은 사용하지 않는다.
5. 산출 기준은 가능한 경우 `회당 금액 × 횟수 · 1회당 시간`으로 짧게 표시한다.
6. 단가·횟수가 없는 구버전 데이터는 시간만 표시하고 불필요한 `확정 금액 직접 입력` 문구를 노출하지 않는다.
7. `Access 원본 합계` 대조는 편집 영역에만 남고 학부모 안내서에는 표시하지 않는다.
8. 원본 붙여넣기 데이터가 있는 구버전 저장본은 불러올 때 현재 파서로 다시 분석해 빈 `■금액` 행을 제외한다.

## 불변 조건

- 납부 행은 최종 합계에서 차감한다.
- 초과금은 더하고 이월금은 뺀다.
- 수강료 소계와 최종 미납/차액은 `tabular-nums`로 정렬한다.
- 이미지 저장, 서버 저장/불러오기, 행 직접 수정 기능은 유지한다.
