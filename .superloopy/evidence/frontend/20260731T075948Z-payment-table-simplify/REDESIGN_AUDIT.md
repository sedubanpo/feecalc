# 납부/차액 안내서 간결화 감사

- 모드: Preserve
- 근거: 사용자는 기존 계산기 구조와 브랜드를 유지하면서 납부/차액 안내서의 과도한 카드 표현만 줄이도록 요청했다.
- 대상: 공개 GitHub Pages의 한국어 DOM 기반 업무용 계산기
- 기준 화면: 사용자가 제공한 2026-07-31 Chrome 캡처

## 브랜드와 구조

- 권위 소스: `DESIGN.md`와 `index.html`의 기존 에스에듀 블루·보라 기능색
- 유지: 로고, 상단 탭, 입력/저장 흐름, 안내서 제목, 수강료·조정·납부·최종합계 순서
- 변경하지 않음: URL, 탭 이름, 필드 이름, Supabase 저장 구조, 이미지 저장

## 현재 문제

- 대과목별 카드와 중첩된 흰색 내부 표면이 동일 정보를 여러 겹으로 감싼다.
- 과목 카드의 왼쪽 색 띠가 표의 행 정렬보다 장식에 주의를 끈다.
- 수업마다 긴 산출 문장이 반복되어 과목·강사·금액 비교가 느리다.
- 내부 검증용 `Access 원본 합계`가 학부모용 안내서에 노출된다.
- 구버전 저장본은 과거 `paymentRows` 24개를 그대로 복원해 빈 `■금액` 세 행을 다시 포함한다.

## 보존할 패턴

- 좌측 첫 열에서 대과목을 먼저 식별하는 문서형 표
- 강사명과 수업 유형, 시간 기준, 금액의 숫자 정렬
- 수강료 소계, 조정, 기납부, 미납/차액의 계산 순서
- 편집 영역의 원본 대조 상태와 수정 가능성

## 제거할 패턴

- 과목별 장식 카드, 왼쪽 색 띠, 중첩된 카드 표면
- 안내서 안의 내부 운영 문구 `Access 원본 합계`
- `확정 금액 직접 입력`의 반복 노출

## 시각 방향

- 1개의 선형 표 안에서 `대과목 | 강사·수업 | 산출 기준 | 금액`을 반복한다.
- 대과목 셀은 그룹 첫 행에서만 표시하고 행 병합으로 같은 과목을 묶는다.
- 배경색 대신 헤더와 얇은 구분선, 글자 굵기, 숫자 정렬로 계층을 만든다.
- 과목 사이에는 조금 더 강한 가로 구분선만 사용한다.

- 공개 URL과 문서 제목은 유지한다.
- 검색 순위·분석 이벤트 자료는 unavailable and unverified.
- 이번 성공 기준은 저장본 계산 정확성과 안내서 판독성이므로 차단 요소가 아니다.
