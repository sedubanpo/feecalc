# Design token evidence

프로젝트의 authoritative token contract는 저장소 루트의 `DESIGN.md`다.

- 기존 에스에듀 브랜드·상태 팔레트 95색을 기능별 그룹으로 선언했다.
- 기본 간격은 4px이며, 기존 달력·뱃지 정렬 보존에 필요한 광학 보정값만 명명 토큰으로 선언했다.
- 새 기록 헤더, 단가 입력, 포커스, 모션, 숫자 정렬은 CSS custom property를 사용한다.
- `ds-compliance.json` 결과: `ok: true`, undeclared colors 0, off-scale spacing 0.
