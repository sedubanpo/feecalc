# UX Contract — 고밀도 캘린더·이미지 저장

## 사용자 목표

- 수업이 많은 달에도 안내서 캘린더가 과도하게 길어지지 않아야 한다.
- 캘린더 안에서 과목, 1:1 여부, 수업 시간을 빠르게 구분해야 한다.
- 이미지 저장 결과에서 한글과 숫자, 뱃지 텍스트의 아래쪽이 잘리지 않아야 한다.

## 수용 기준

1. 기본 안내서에서 캘린더 영역은 전체 폭의 약 48%를 사용한다.
2. 1:1 수업은 과목명과 같은 줄의 작은 `1:1` 표지로 표시하고, 시간은 다음 줄에 둔다.
3. 47개 수업·1:1 21건의 고밀도 표본에서 날짜 셀 내용 넘침이 없어야 한다.
4. 이미지 저장은 1120px 기준 폭과 2배율을 유지하며, 캡처 전용 줄높이·아래 여백을 적용한다.
5. 캡처 시 안내서 그림자를 제거해 html2canvas의 과대 그림자 렌더링을 방지한다.
6. 이미지 저장 버튼은 최소 44px 클릭 영역, 키보드 포커스, 안정된 아이콘/문구 정렬을 제공한다.

## 범위 외

- 계산식, Supabase 저장 구조, 인증 구조는 변경하지 않는다.
- 모바일 전용 레이아웃 재설계는 PC 중심 제품 범위에 포함하지 않는다.
