# 안내서 캘린더 시간·상태 표시

안내서(현재 달 및 이전 달)의 캘린더는 첫 줄에 과목/회당 시간, 두 번째 줄에 강사/상태를 표시한다. 유효한 시작·종료 시각 차이로 예정 수업 길이를 구하고 시각이 없으면 기록 시수를 사용한다. 결석으로 청구 시수가 0이어도 일정이 있으면 예정 길이를 표시한다. 알 수 없는 시간은 확인 필요로 유지한다.

출석/예정/예상은 정규, 보충/보강/프리는 보충, 당일취소는 당취, 결석예고는 결석으로 요약한다. 휴강·지각·특강·자습 및 미확인 상태를 유지한다. 기존 당일취소를 출석으로 표시 옵션은 정규 표시로 적용한다. 계산·금액·원본은 변경하지 않는다. 기존 강사/시간 숨김 옵션 유지.

검증: 단위·인증 88개 통과. 브라우저 7개 시나리오 통과(8종 상태, 0원 결석의 일정 길이, 당일취소 표시 옵션 포함). PNG 출력에서 두 줄 배치 및 시간·강사·상태가 셀 안에 들어가는 것을 시각 확인.
