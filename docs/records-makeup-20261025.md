# 저장 기록 버전 탭과 보강·보충 자동 예상 제외

## 변경 범위

- 최근 조회한 저장 기록을 같은 이름별 폴더로 표시하고 최신/이전 버전 탭으로 금액·계산 월·저장 시각을 확인한다. 저장본 열기와 삭제는 선택한 recordId에만 적용한다.
- 탭 전환은 이미 조회한 목록만 사용한다. 조회 한도·검색 RPC·학생 연결 및 저장 스키마는 바꾸지 않았다. 따라서 버전 수는 현재 조회한 목록 기준이다.
- 동명이인 기록은 화면상 같은 폴더에 있어도 payload와 학생 ID를 합치지 않는다. 선택 버전의 학생 ID가 확인되면 해당 학교를, 확인되지 않으면 동명이인 안내를 표시한다.
- 자동 예상 기준에서 absenceMakeup, cancelMakeup, lateMakeup, free와 보강·보충으로 명시된 수업을 제외한다. 실제 수업과 청구액은 그대로 두며, 저장된 직접 추가 날짜도 유지한다.
- 같은 요일의 보강이 정규 시간·시수·단가를 대체하지 않는다. 이미 입력된 다른 시간대의 보강 때문에 정규 예상이 없어지지 않도록 날짜 중복 검사를 보완했다. 시간이 불명확하거나 겹치면 보수적으로 중복 생성을 막는다.
- 결석예고의 정규 단가를 복구할 때 보강 단가를 사용하지 않는다. 정규 단가가 확인되지 않으면 확인 필요 상태를 유지한다.
- 다음 달 수업 후보에서도 보강 표기를 제외한다. 계산기에서 보강으로 바꾼 회차는 자동 반복 기준에서 제외하지만, 개별 날짜·금액·시간 수정으로 정규 패턴을 다시 쓰거나 원본 보강을 정규 수업으로 승격하지 않는다.

## 검증

- Node 격리 테스트 87개 통과: 진행형, 다음 달 후보, 실제 수업 금액, 직접 추가, 미확인 금액, 저장본 그룹, 중복 요청 공유, 확정 직전 fresh 검증, 금융 원본 보존.
- `tests/record-forecast.browser.cjs` 통과: 폴더/탭, 탭 전환 추가 RPC 0회, 열기·삭제 recordId 일치, 키보드, 검색 후 재표시, 로드된 버전 선택, 동명이인 학교 구분, 보강 예상 제외, 1440px/390px 화면. 인증과 RPC는 합성 데이터이며 운영 서비스 호출은 차단했다.
- 화면 증거: `/tmp/feecalc-record-forecast/desktop.png`, `mobile.png`, `result.json`.
- 기존 `tests/fee-ui.cjs`는 앞 10개 확인 통과 후 105행에서 시작 시각 `20:30` 표시를 기대하여 실패한다. 현재 안내서가 회당 시간(`2.5시간`)을 표시하도록 바뀐 뒤 갱신되지 않은 검사다. 변경 전 HEAD `7b73d93`을 별도 로컬 서버로 실행해 동일 실패를 재현했다. 이 테스트 전체가 통과했다고 주장하지 않는다.
- 디자인 검사는 기존 워터마크·옛 모달·기존 CSS 경고를 포함한다. 사용자 지정 워터마크와 기존 화면을 유지했고 새 폴더의 실제 줄바꿈·선택 상태·키보드·모바일 넘침을 별도로 확인했다.

공용 서버, 인증/권한, 금융 확정 직전 최신성 검증, 운영 학생·수납 데이터는 변경하지 않았다. 배포 확인은 공개 정적 파일의 바이트 비교와 배포 결과로 수행한다.
